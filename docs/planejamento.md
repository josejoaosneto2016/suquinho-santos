# Planejamento do projeto

## Objetivo

Criar um site simples de encomendas para o Suquinhos Santos e, em etapas, um painel de uso familiar para organizar pedidos e finanças.

## Etapa 1 — Base visual (iniciada)

- [x] Criar estrutura de pastas e documentos.
- [x] Incluir logo fornecida, cores verde e laranja e os três sabores.
- [x] Mostrar preço de R$ 12,00 por garrafa.
- [x] Criar cesta demonstrativa local.
- [ ] Rever a aparência e a descrição dos sabores em família.

## Etapa 2 — Operação de encomendas

- [ ] Definir canal de pedido, prazo semanal, região e logística de entrega/retirada.
- [ ] Definir tamanho da garrafa, disponibilidade e políticas de cancelamento.
- [ ] Registrar pedidos e quantidades por sabor para orientar compras de sábado.
- [ ] Organizar status de pagamento, produção e entrega de segunda.
- [ ] Confirmar com clientes sem expor dados publicamente.

## Etapa 3 — Painel familiar

- [ ] Escolher autenticação e armazenamento adequados antes de registrar dados reais.
- [ ] Implementar papéis e permissões de adulto responsável e colaborador jovem.
- [ ] Criar resumo de pedidos, caixa, custos e despesas.
- [ ] Criar relatórios, metas e histórico de clientes com acesso controlado.
- [ ] Adicionar exportação e rotina de backup e testar recuperação.

## Etapa 4 — Preparar publicação

- [ ] Revisar conteúdo, acessibilidade, telas pequenas e links.
- [ ] Confirmar domínio/plataforma e responsável adulto pelas contas.
- [ ] Definir aviso de privacidade e canal de suporte antes de aceitar pedidos reais.
- [ ] Publicar depois de revisão conjunta.

## Rotina semanal representada

Semana: coleta de encomendas → sábado: compra baseada nos pedidos → domingo: organização → segunda: produção e entrega. O site não promete disponibilidade de produto pronto em estoque.
