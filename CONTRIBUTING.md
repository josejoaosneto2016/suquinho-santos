# Contribuindo em família

Este projeto é desenvolvido em conjunto. A ideia é que cada pessoa possa propor mudanças pequenas, explicar o que fez e revisar com a outra.

## Combinados

- Conversem antes de alterar regras de preço, sabores, agenda ou dados de clientes.
- Dividam tarefas pelo quadro do Trello. Escolham uma tarefa por vez e indiquem quem está trabalhando nela.
- Façam mudanças pequenas e salvem com frequência no GitHub.
- Antes de integrar o trabalho, abram uma solicitação de revisão (Pull Request) e descrevam objetivo, arquivos alterados e como conferir.
- A outra pessoa revisa com gentileza, pede ajustes quando necessário e confirma que entendeu a mudança.
- Guardem decisões de produto em `docs/funcionalidades.md` e atualizem este README quando as instruções mudarem.

## Fluxo sugerido no GitHub

1. Sincronize a cópia local com a versão mais recente.
2. Crie uma branch com nome simples, por exemplo `feat/cardapio` ou `docs/rotina-semanal`.
3. Edite e confira a página localmente.
4. Salve as alterações com uma mensagem clara, por exemplo `feat: adiciona cardápio de sabores`.
5. Envie a branch e abra um Pull Request para revisão do familiar.
6. Depois da revisão, integrem a mudança e atualizem a cópia local.

Não coloquem senhas, tokens, dados bancários ou dados reais de clientes no repositório. Para publicar o site ou ligar serviços, conversem e definam primeiro quem administra as contas e acessos.
